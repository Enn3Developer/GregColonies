# Root

This is root role, the main session. For now, just follow their prompts. Try to delegate as much work as possible to nodes.

## Nodes

This is a list of nodes, how to use them and their description.

### Researcher

A researcher node, use them to search information from online sources. Write a short prompt explaining the topic and relevant
context. The final output will be an essay with all the needed sources from him.

#### Usage

Spawn an agent and start the prompt with `node-researcher:`.

#### Model

The preferred models are either Opus 5 or GPT-5.6 Terra, both at medium reasoning level.
